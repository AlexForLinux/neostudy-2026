## Размещения моделей типа qwen3.5
Отдельно рассотрим рассчеты для моделей Qwen3.5

### Подход к расчетам KV-кеша
Поскольку у qwen3.5 моделей гибридная архитектура, определим формулу расчета kv-кеша и покажем ее корректность.
За основу возьмем формулу для вычисление размера одного параметра из источника [3], представленного в конспекте по инференсу:

> 2 * layers * heads * head_dim * kv_param_weight

Определим переменные, как:
1. 2 - число матриц (K и V)
2. layers - число attention слоев
3. heads - число голов для KV в attention слое
4. head_dim - размерность головы
5. kv_param_weight - вес параметра kv-кеша, байт (в [3] = 2 байт)

Соотвественно для заданного контекст context, размер KV-кеша:
> 2 * layers * heads * head_dim * kv_param_weight * context

#### Предположение
Пусть есть модель qwen3.5-2b, для которой layers = 6, heads = 2, head_dim = 256, kv_param_weight = 2
Для контекстов 8192, 16384:
```
2 * 6 * 2 * 256 * 2 * 8192 = 96 MB
2 * 6 * 2 * 256 * 2 * 16384 = 192 MB
```

#### Проверка через llama.cpp

Выполним запуск с контекстом 8192:

> llama-server -m ".\Qwen3.5-2B-BF16.gguf" -c 8192

В выводе увидим:
```
llama_kv_cache:      CUDA0 KV buffer size =    96.00 MiB
llama_kv_cache: size =   96.00 MiB (  8192 cells,   6 layers,  4/1 seqs), K (f16):   48.00 MiB, V (f16):   48.00 MiB
llama_kv_cache: attn_rot_k = 0, n_embd_head_k_all = 256
llama_kv_cache: attn_rot_v = 0, n_embd_head_k_all = 256
```

Выполним запуск с контекстом 16384:

> llama-server -m ".\Qwen3.5-2B-BF16.gguf" -c 16384

В выводе увидим:
```
llama_kv_cache:      CUDA0 KV buffer size =   192.00 MiB
llama_kv_cache: size =  192.00 MiB ( 16384 cells,   6 layers,  4/1 seqs), K (f16):   96.00 MiB, V (f16):   96.00 MiB
llama_kv_cache: attn_rot_k = 0, n_embd_head_k_all = 256
llama_kv_cache: attn_rot_v = 0, n_embd_head_k_all = 256
```

**Результаты сошлись, чтд.**

### Подход к расчетам для модели
Воспользуемся формулой из конспекта по инференсу и истоника [4]:

> 1.2 * params * param_weight

Определим переменные, как:
1. 1.2 - допущение для активаций и key-value векторов у attention-механизма
2. params - число параметров модели (K и V)
3. param_weight - вес параметра модели, байт
